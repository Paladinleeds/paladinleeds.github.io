# Support Portal

If you're having trouble with a plugin, there are 2 stages in the "self-service" part of support, these are as follows:

## 1. Checking the help pages

Every piece of software will have its own (set of) page(s) of information surrounding it. In the first instance you should check these pages and see if it solves your issue. FAQs will be included on these pages in order to help save time.

## 2. Accessing Discord

If you cannot find your answer on our help pages, then you will need to [join our Discord here](http://discord.gg/tmnv48e). Once you join the server, state in the onboarding process that you wish to receive technical support. This will give you access to the help channels.
